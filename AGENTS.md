# Agent Hub: instrucciones para agentes

Las instrucciones de este repositorio para cualquier agente de código están en [`CLAUDE.md`](CLAUDE.md). Léelo entero antes de cambiar nada: valen igual para un agente que no sea Claude Code, y este fichero existe solo porque no todos los agentes leen aquel.

Aquí no hay más reglas que las de allí. Si alguna vez este fichero y `CLAUDE.md` dijeran cosas distintas, vale `CLAUDE.md`.

Lo primero que dice, para quien llega:

- **Antes de tocar nada, `docs/HANDOFF.md`:** las decisiones del dueño, lo hecho, lo que no está comprobado y lo pendiente.
- **`npm install` y `npm test`:** los tests pasan todos antes y después de cada cambio.
- **Bloques pequeños y terminados:** tests en verde, README al día y un commit por bloque.
- **Nada se despliega ni se crea en una nube** sin que el dueño lo confirme.
- **Código, comentarios y errores en inglés;** README, documentación y textos para el usuario en español.
